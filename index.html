Enviar relatório do Instagram

Envie o arquivo .zip do relatório. A primeira vez mostra quem não te segue de volta; as próximas mostram também quem parou de te seguir desde o relatório anterior. Tudo é processado neste aparelho; nada é enviado para a internet.

Como baixar o relatório
  1. No Instagram: Perfil → menu ☰ → Central de Contas.
  2. Suas informações e permissões → Baixar suas informações.
  3. Baixar ou transferir informações → escolha a conta.
  4. Algumas das suas informações → marque só Seguidores e seguindo.
  5. Baixar no dispositivo → Intervalo: Desde o início · Formato: JSON → Criar arquivos.
  6. Quando o Instagram avisar que está pronto, baixe o .zip (no iPhone ele vai para Arquivos → Downloads) e abra aqui. Não precisa descompactar.

Se o .zip não abrir, toque nele no app Arquivos para descompactar e envie juntos os arquivos followers_1.json e following.json (pasta connections → followers_and_following).
